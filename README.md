# DigiSeal-XML

**DigiSeal-XML** – десктопное приложение для создания отсоединённой электронной подписи XML-документов с использованием сертифицированного криптопровайдера «КриптоПро CSP».

## Возможности

- Выбор одного или нескольких XML-файлов через стандартный диалог
- Управление списком подписантов (добавление/удаление) с сохранением в JSON-файл
- Формирование электронной подписи в формате detached signature (файл `.sig`)
- Диагностика состояния криптографической среды (доступность CSP, сертификаты)
- Логирование всех операций в файл с ротацией
- Интуитивно понятный графический интерфейс на PyQt5

## Технологии

- **Python** 3.10+
- **PyQt5** – графический интерфейс
- **КриптоПро CSP** – криптографический провайдер (ГОСТ)
- **pywin32** – взаимодействие с COM-объектами Windows
- **loguru** – логирование
- **pytest** – юнит-тестирование
- **GitHub Actions** – CI/CD (автоматическое тестирование и сборка)

## Установка и запуск

### Требования

- Операционная система Windows 10/11
- Установленный криптопровайдер «КриптоПро CSP» (лицензионная версия)
- Действующий сертификат электронной подписи в системном хранилище
